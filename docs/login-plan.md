# 로그인·랭킹 PR 통합 기록

[PR #1: Feature/login ranking](https://github.com/jinw2540/crowd-runner/pull/1)의 Google 로그인, 닉네임, 클라우드 진행도, 탐험 랭킹을 무한 모드와 통합했습니다. 원 PR 작성자: `elielieli-kim`. 실제 연결 절차는 [online-setup.md](online-setup.md)를 따릅니다.

## 반영한 동작

- Google OAuth 로그인/로그아웃. 무한 랭킹은 익명 로그인도 지원하고 Google 계정 연결을 제공합니다.
- 닉네임 2~12자, 중복 방지, 텍스트로 렌더링.
- 기존 기기 진행도는 첫 영구 계정에 가져옵니다. 계정별 로컬 저장을 분리하고 로그아웃하면 게스트 저장으로 돌아갑니다.
- 로그인 시 기기·서버 진행도의 큰 값을 합칩니다. 코인은 더하지 않습니다. 일반 플레이의 이후 저장은 실제 잔액을 전송합니다.
- 스테이지 → 별 → 갱신 시각 순으로 상위 100명과 내 순위를 표시합니다.
- 저장 중 다시 변경된 진행도, 늦게 도착한 이전 계정의 응답을 구분합니다.
- 서버 SQL에서 진행도 범위·JSON 형식을 검증하고 직접 쓰기를 막습니다. 원 PR의 처음 5회 기기 기록 가져오기 정책을 유지합니다.

탐험 저장/순위는 원 PR의 진행도 범위 검사 방식입니다. 무한 모드 점수는 별도 입력 재계산으로 확정하므로 두 랭킹을 구분합니다. Google 로그인이나 클라우드 저장 오류가 나도 기기의 진행도와 연습 모드는 유지합니다.

## 공개 전에 남은 확인

실제 Supabase URL·공개 키 입력, SQL 적용과 Edge Function 배포, Google 공급자·리디렉션·Manual Linking 설정, 실제 두 기기 로그인 검증이 필요합니다. 현재 저장소에는 운영 프로젝트 키가 없습니다.
