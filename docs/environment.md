# 얼음 환경과 바다

길, 유빙, 바다는 모두 코드로 만든 모델입니다. 외부 텍스처나 모델 파일을 쓰지 않습니다.

## 얼음길

- 눈이 덮인 하나의 이어진 얼음판입니다. 양 끝의 둥근 모서리는 그대로 두고 가운데만 스테이지 길이에 맞게 늘립니다.
- 펭귄이 달리는 가운데 10유닛은 평평합니다.
- 작은 눈 둔덕과 옅은 균열은 늘리지 않고 원래 크기로 반복해 놓습니다.

## 유빙

네 가지 모양이 있습니다: 작은 유빙, 눈 쌓인 유빙, 큰 유빙, 뾰족한 유빙. 뾰족한 유빙은 높이와 기울기가 다른 다섯 개의 깨진 얼음판에 눈이 붙은 모양입니다. 눈사람이 서 있는 받침과 보스 앞의 넓은 빙판도 같은 모델을 씁니다.

### 배치

- 길의 왼쪽과 오른쪽을 따로 배치합니다. 줄을 맞추거나 좌우 대칭으로 놓지 않습니다.
- 작은 유빙 2~4개가 모인 무리, 중간 유빙, 드문 큰 유빙을 섞고, 중간중간 넓게 비운 수면을 둡니다.
- 큰 유빙과 뾰족한 유빙은 길에서 더 멀리 놓습니다.
- 실제 모델 크기에 맞춘 여유 거리를 두어 유빙끼리, 그리고 눈사람 받침·결승 빙판·길과 겹치지 않습니다.
- 배치는 스테이지 번호로 정해지므로 다시 시작해도 같습니다. 장식용 난수는 게이트와 장애물을 만드는 난수와 분리되어 있어, 장식을 바꿔도 스테이지 구성은 달라지지 않습니다.

### 크기와 간격 조절

`js/environment.js` 위쪽의 `FLOE_LAYOUT`에서 조절합니다.

| 설정 | 현재 값 | 효과 |
|---|---|---|
| `smallScale` | `min: 0.9, max: 3.0` | 작은 유빙의 크기. `min`을 올리면 아주 작은 조각이 줄어듭니다. |
| `smallSnowyScale` | `min: 0.8, max: 4.0` | 작은 무리에 섞이는 눈 쌓인 유빙의 크기. 원본 모델의 크기가 달라 따로 조절합니다. |
| `gap` | `min: 0.9, max: 2.5` | 두 유빙 사이에 두는 여유 거리. 올리면 더 떨어집니다. |
| `clusterSpacing` | `21` | 유빙 무리끼리의 최소 거리. 올리면 무리 사이가 더 벌어집니다. |

- 크기는 `1`이 원본 모델 크기이고, 거리는 게임 월드 단위입니다.
- 각 범위의 `min`은 `max`보다 크면 안 됩니다.
- 예: 작은 조각만 키우려면 `smallScale.min`을 `1.10`으로 올립니다. 간격을 넓히려면 `gap`을 `{ min: 1.4, max: 2.6 }`으로 바꿉니다.
- 실제 거리는 모양과 무리 배치, 빈 수면 때문에 설정한 값보다 클 수 있습니다. 값을 너무 크게 잡으면 놓을 자리가 줄어 유빙 수가 줄어듭니다.
- 저장하고 페이지를 새로 고치면 반영됩니다.

### 움직임

유빙은 6.8초 주기로 작게 떠오르고 기울어집니다. 작은 유빙도 물에 잠겨 보이도록 높이를 맞춥니다.

## 바다

- 가까운 곳은 맑은 청록색이고 멀어질수록 하늘색이 됩니다.
- 두 방향의 완만한 물결과 작은 잔물결을 계산해 빛을 흩뜨립니다. 반복되는 선 무늬 텍스처를 쓰지 않습니다.
- 물결은 월드 좌표에 고정되어 있어, 카메라가 달려도 함께 미끄러지지 않습니다.
- 그림자와 안개를 그대로 받습니다. 반사를 위한 별도의 렌더링은 하지 않습니다.

### 거품

유빙의 실제 외곽선과 길의 물가를 따라 얇고 불규칙한 거품과 청록빛을 놓습니다. 거품은 바다와 같은 물결과 같은 시계를 씁니다.

## 조명과 색감

- 부드러운 햇빛, 푸른빛이 도는 그늘, 카메라 쪽에서 비추는 보조광을 씁니다. 밝은 배경에서도 남색 펭귄과 산호색 게가 구분됩니다.
- 눈 재질은 작은 굴곡이 드러나도록 밝기를 맞췄습니다.
- 캐릭터 쪽 색 보정은 [캐릭터 문서](characters.md#색-보정)에 있습니다.

## 접근성과 성능

- 기기의 **동작 줄이기** 설정을 켜면 유빙, 물, 거품의 움직임을 멈춥니다.
- 얼음과 눈은 재질 두 개만 씁니다. 반투명이 겹치는 부분이 없습니다.
- 같은 모양의 유빙은 모델과 재질을 공유하고, 구간별로 묶어 그리며, 멀리 있는 구간은 숨깁니다.
- 거품도 구간별로 묶습니다.
- 다시 시작할 때는 길과 구간별 버퍼만 새로 만들고, 공유하는 모델과 바다는 다시 씁니다.
